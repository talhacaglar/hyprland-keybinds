# Hyprland Keybindings

[English](#english) · [Türkçe](#türkçe)

## English

Personal keyboard shortcuts for Hyprland, stored in `keybindings.conf`.

### Features

- A standalone shortcut configuration to inspect and adapt.

### Getting started

Read [keybindings.conf](keybindings.conf), adjust executable names and paths for your setup, and include the file from your Hyprland configuration.

## Türkçe

`keybindings.conf` dosyasında tutulan kişisel Hyprland klavye kısayolları.

### Özellikler

- İncelenip uyarlanabilen bağımsız kısayol yapılandırması.

### Başlangıç

[keybindings.conf](keybindings.conf) dosyasını okuyun, komut adlarını ve yolları sisteminize uyarlayın; dosyayı Hyprland yapılandırmanızdan dahil edin.
